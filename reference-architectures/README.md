# Reference architectures

A reference architecture here is a vendor-neutral, sanitised description of how a class of system fits together. It is not a client deliverable. It will not include client data, employer data, or material from a live engagement.

Two notes are available. They describe a pattern. They are not a record of a particular engagement. The other rows are still planned. A note is added only when there is a real pattern to publish.
