# Brand Assets

Published, web-optimised brand assets for **Naya Kai**. These files are referenced directly by the repository `README.md`, so they must remain public and at stable paths.

## Contents

| File | Size | Use |
| :--- | :--- | :--- |
| `naya-kai-banner.png` | 1400 × 781 | Repository README banner, profile header, presentation cover |
| `naya-kai-logo.png` | 600 × 600 | Primary lockup — wordmark with mark, for square and near-square placements |
| `naya-kai-mark.png` | 400 × 400 | Compact mark — avatars, favicons, repository badges |

## Storage policy

This repository holds **published assets only**. Source and working material live elsewhere.

| Material | Location | Rationale |
| :--- | :--- | :--- |
| Banner, logo lockup, compact mark (web-optimised) | This repository, `assets/` | GitHub serves README images from the repository, so they must be public |
| Master vector sources, raw generations, working files | Private repository `naya-kai/brand-repo` | Keeps the public repository lightweight; source files are not for public consumption |
| Brand guideline | Private repository `naya-kai/brand-repo` | Contains the full visual system, tagline strategy and platform usage — not for public consumption |
| Branding journey transcript | Private only | Contains family names, account strategy and employer context |
| Curriculum vitae | Private only | Personal data |

## Adding or replacing an asset

1. Produce the master in the private `brand-repo` repository.
2. Export a web-optimised raster at the sizes in the table above.
3. Commit only the export here, keeping the filename stable so existing references do not break.
4. Update the size column above if the dimensions change.
